# VoucherPass v8.8.0

Windows용 증빙 서류 등록·추출·인쇄·보관 도구입니다. 내부 시스템에 직접 업로드하거나 거래 건을 자동 확정하는 기능은 포함하지 않습니다.

## 사용

- PDF 5종을 해당 칸에 선택하거나 드롭합니다. 세금계산서 칸은 HTML도 지원합니다.
- F4: 현재 선택/열람 중인 Outlook 메일의 PDF·HTML 첨부파일을 COM으로 가져옵니다. Classic Outlook과 pywin32가 필요합니다.
- 자동 분류 실패 또는 이미 사용 중인 문서 칸은 안내를 확인하고 직접 파일을 선택합니다. 자동 가져오기는 기존 문서를 교체하지 않습니다.
- F6: Excel 템플릿을 선택해 전표 파일을 바탕화면에 저장합니다. 매핑은 `excel_handler.py`에 정의되어 있습니다.
- F7: 계약서 지정 페이지를 바탕화면에 별도 PDF로 저장합니다. `1,3-5` 형식으로 입력합니다.
- Ctrl+Shift+V 또는 Ctrl+Alt+V: 위젯 호출. F4를 여러 번 눌러도 동시에 중복 가져오지 않습니다.
- Ctrl+V: 파일 탐색기에서 복사한 실제 파일 경로를 가져옵니다. Outlook 가상 첨부파일은 F4를 사용합니다.
- 엑셀 양식 붙여넣기 버튼은 날짜·제목·공급가액을 세 행으로 복사합니다. 엑셀에 직접 입력하려면 셀 선택 후 붙여넣습니다.

## 데이터 처리 규칙

- PR 번호·제목은 PR에서만 읽습니다. PR 금액이 있으면 이를 입력 기본값으로 사용하며, PR이 없으면 세금계산서, 그다음 PO 순입니다.
- 거래처는 PO 우선, 날짜는 세금계산서 우선입니다. 선택된 문서의 추출 실패는 빈 값으로 남기며 이전 문서 값으로 대체하지 않습니다.
- 원본 비교 금액과 화면 입력 금액은 분리되어 있습니다. 수동 수정은 원본 PR/세금계산서 비교값을 바꾸지 않습니다. 새 문서 분석 완료 시 문서별 우선순위로 입력 기본값이 다시 적용되므로 수동 보정은 문서 등록 후 진행합니다.
- 공급가액·세액·합계의 명시적 값을 읽습니다. 두 값이 확인되면 나머지 한 값만 산술 계산합니다. 공급가액을 최대 금액으로 추정하거나 세액을 일괄 10%로 계산하지 않습니다.
- 미추출·서로 다른 후보·합계 불일치는 확인 필요로 표시합니다. 스캔 PDF OCR은 지원하지 않으므로 수동 확인이 필요합니다.
- 등록 배지는 파일 선택 상태입니다. 추출/변환 성공 여부는 상태 메시지와 입력값을 확인합니다.
- HTML 변환은 Edge, Selenium 및 호환 WebDriver가 필요합니다. 드라이버 준비에 네트워크가 필요할 수 있으므로 사내 환경에서는 호환 드라이버를 PATH에 미리 준비합니다.
- `VOUCHERPASS_PDF_PASSWORD` 환경변수로 PDF/HTML 비밀번호를 지정할 수 있습니다. 미설정 시 기존 업무용 기본값을 사용합니다.
- 폴더 자동 감시는 기본 비활성화입니다.

## 출력과 저장

전체 인쇄 대상의 PDF 읽기와 계약서 범위를 검증한 후 인쇄 요청을 보냅니다. 범위가 잘못되면 전체 인쇄로 전환하지 않습니다. 타임아웃 후 재인쇄는 자동으로 수행하지 않으므로 프린터 대기열을 확인합니다. 요청 성공은 물리적 출력 완료를 보장하지 않습니다.

첨부파일·변환 PDF·인쇄 사본은 `%TEMP%/VoucherPass`의 작업별 폴더에 저장합니다. 인쇄 프로그램이 비동기로 파일을 읽으므로 즉시 삭제하지 않습니다. 앱과 인쇄 작업을 모두 종료한 뒤 해당 임시폴더를 정리할 수 있습니다.

건별 보관은 매번 고유 폴더를 만들고 문서 유형을 파일명에 붙입니다. 같은 파일명이나 같은 건을 다시 보관해도 기존 파일을 덮어쓰지 않습니다. 인쇄·저장 중에는 리셋을 제한합니다. 분석 중 리셋하면 늦게 도착한 결과는 화면에 적용되지 않습니다.

## 개발 및 빌드

Windows Python 3.12와 Tk가 설치된 환경에서 실행합니다. 아래 버전은 기존 개발 PC의 직접 의존성 버전이며, 전체 전이 의존성 잠금 파일은 아닙니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-build.txt
.\.venv\Scripts\python -m unittest discover -s tests -v
.\.venv\Scripts\python main.py
.\.venv\Scripts\python make_installer.py
```

`make_installer.py`는 두 spec을 순서대로 clean 빌드합니다. 결과는 `dist/v8.8.0/VoucherPass.exe`, `dist/v8.8.0/VoucherPass_Setup.exe`입니다. 캐시는 `build/v8.8.0/`에 저장하며 이전 버전 파일과 분리합니다. `assets/` 아이콘과 `bin/SumatraPDF.exe`가 필요하며 특정 사용자 절대경로는 사용하지 않습니다.

설치 프로그램은 기존과 동일하게 Public/VoucherPass에 설치하고 현재 사용자 바로가기·시작프로그램을 등록합니다. 기존 프로그램을 종료한 후 업데이트합니다.

디버그 로그는 기본 꺼짐입니다. 필요한 경우 `VOUCHERPASS_DEBUG=1`을 설정하며, 업무 정보가 포함될 수 있으므로 공유 전 내용을 확인합니다. 로그·임시파일·신규 빌드 출력은 Git에서 제외합니다. GitHub 용량 제한을 초과한 기존 dist/VoucherPass.exe와 build/VoucherPass/VoucherPass.pkg는 Git 추적에서 제외했으며 실제 로컬 파일은 유지합니다. 정리 전 이력은 로컬 codex/local-backup-v8.8.0 브랜치에 보존합니다.

## 검증

회귀 테스트는 금액/문서 상태, 실제 임시 PDF의 페이지 검증·추출, Excel 저장, 파일 충돌 방지, 비동기 결과 무효화, 숨긴 Tk 창의 등록·리셋을 확인합니다. Outlook·실물 프린터는 테스트에서 조작하지 않습니다.

배포 전 실제 업무용 PR/PO/세금계산서 양식, Outlook 첨부파일, Edge HTML 복호화, 프린터 출력 및 설치 프로그램을 별도로 확인해야 합니다. 정규식 파싱이므로 새로운 양식은 확인 필요 상태가 될 수 있습니다.
